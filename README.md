# LibrarySphere

LibrarySphere is a library management system designed for catalog management, member administration, circulation, reporting, and audit tracking.

## Phase 1: Project Setup

This repository has been initialized with the required project skeleton for the backend and frontend application layers.

## Stack

- Backend: Node.js + TypeScript + Express
- Frontend: React + TypeScript + Vite
- Database: PostgreSQL via `pg`
- Configuration: `.env` with environment variables

## Project structure

- `server/` — API and backend configuration
- `client/` — frontend starter app

## Getting started

1. Copy `.env.example` to `.env`.
2. Update the database and security values as needed.
3. Install dependencies:
   `npm install`
4. Start the app:
   `npm run dev`

## Notes

This repository contains only the Phase 1 project setup. Database schema, authentication, and business modules will be implemented in later phases.
